# Identivize Homebrew tap

Homebrew tap for [Relay Factory](https://github.com/Identivize/relay-factory).

Once the first stable release ships, this installs the `factory` CLI:

```sh
brew install --cask identivize/tap/relay-factory
```

The cask in `Casks/` is written by the Relay Factory release workflow;
prereleases do not update it.
